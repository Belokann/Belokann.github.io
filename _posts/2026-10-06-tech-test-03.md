블로그 글을 수정한 뒤 변경 사항을 확인하는 간단한 작업 흐름입니다. 화면 확인용 테스트 글입니다.

## 변경 사항 확인

```bash
git status
git diff
```

## 작업 순서

1. 글을 작성하거나 수정합니다.
2. 로컬에서 목록과 본문을 확인합니다.
3. 변경 사항을 검토하고 커밋합니다.

**확인할 내용:** 코드 블록, 굵은 글씨, 순서 목록이 읽기 편하게 표시되는지 살펴봅니다.
