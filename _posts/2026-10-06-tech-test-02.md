기술 글에 들어가는 코드 블록이 어떻게 표시되는지 확인합니다.

## 인사 함수

```python
def greet(name: str) -> str:
    return f"Hello, {name}!"


print(greet("Belokan"))
```

## 실행 결과

```text
Hello, Belokan!
```

짧은 설명 안에 들어가는 `greet()` 같은 인라인 코드도 함께 확인합니다.
